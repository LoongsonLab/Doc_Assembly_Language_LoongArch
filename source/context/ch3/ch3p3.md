#	转移指令

转移指令用于执行有条件或无条件的分支跳转、函数调用、函数返回和循环控制等操作。LoongArch支持的转移指令如表3-9所示。

```{image} ../../img/ch3/t2p_3_9.png
:alt: LoongArch支持的转移指令
:class: bg-primary
:scale: 80 %
:align: center
```

在表3-9中，转移指令助记符有两种命名方式：相对跳转（地址计算依赖PC值）称为“分支”（Branch），助记符以`b`开头；绝对跳转（地址计算不依赖PC值）称为“跳转”（Jump），助记符以`j`开头。

这里的PC为程序计数器，用于控制程序中指令的执行顺序。程序正常运行时，PC总是指向CPU将要执行的下一条指令。当CPU取出下一条指令后，会自动修改PC值，使其指向再下一条指令，从而保证指令按顺序执行。当程序执行顺序发生改变（即发生跳转）时，就需要提前修改PC值，使其指向接下来要跳转的目标指令地址。

表3-9中的转移指令可从有条件分支指令、无条件分支指令和跳转指令、跳转范围几个方面进行说明。

##	有条件的分支指令

表3-9中，`beq`、`bne`、`blt`、`bge`、`bltu`、`bgeu`、`beqz`、`bnez`都是有条件相对跳转指令。当条件成立时，程序跳转到目标地址；否则不跳转。目标地址的计算方式为：将指令码中的立即数（offs16或offs21）逻辑左移2位后进行符号扩展，再将所得偏移值加上该分支指令的PC。条件分别为等于（eq）、不等于（ne）、小于（lt/ltu）、大于或等于（ge/geu）、等于零（eqz）、不等于零（nez），其中ltu、geu表示比较条件针对无符号操作数。

有条件分支指令常用于函数内部的程序流控制，类似C语言中的`if-else`、`do-while`、`for`循环等语句。

##	无条件分支指令和跳转指令

在表3-9中，指令`b`、`bl`均为无条件分支指令，用于无条件跳转到目标地址。目标地址的计算方式为：先将指令码中的26位立即数offs26逻辑左移2位后进行符号扩展，再将所得偏移值加上该分支指令的PC。指令`b`和`bl`的区别在于，`bl`是带链接的无条件分支指令（Branch and Link），即跳转前需要将该指令PC值加4的结果写入寄存器r1。

在表3-9中，指令`jirl`为无条件跳转指令，也用于无条件跳转到目标地址。目标地址的计算方式为：先将指令码中的16位立即数offs16逻辑左移2位后进行符号扩展，再将所得偏移值加上寄存器rj中的值。指令中的`ir`分别代表立即数（Immediate）和寄存器（Register），表示该指令跳转目标地址基于“寄存器+立即数”（绝对跳转）而非PC。指令中的`l`代表带链接的无条件跳转（Jump and Link），表示跳转的同时需要将该指令PC值加4的结果写入寄存器rd。

在LoongArch ABI中，寄存器r1被规定为返回地址寄存器ra。关于LoongArch ABI，后续章节将详细介绍。

分支指令`bl`通常用于函数调用，跳转指令`jirl`通常用于函数返回。

##	跳转范围

表3-9中的分支指令`beq`、`bne`、`blt`、`bltu`、`bge`、`bgeu`的偏移量为offs16，地址计算时还要将其左移2位，共18位，因此可达到的相对跳转范围是[PC-128K, PC+128K]。无条件分支指令`b`、`bl`的地址偏移量为offs26，地址计算时也要左移2位，共28位，因此可达到的相对跳转范围为[PC-128M, PC+128M]。这个跳转范围与ARM架构中的相对跳转范围相同，相比其他早期架构更大。例如MIPS架构的无条件相对跳转范围为[-128K,128K]。

跳转范围增大可以减少地址加载带来的指令开销。举例如下：假设程序需要无条件跳转到范围[PC-128M, PC+128M]内的一个地址（如偏移量为0x40），则仅需一条分支指令`b`即可完成跳转：
``` asm
b 	0x10 	//	跳转到目标地址PC+0x40(0x10<<2)
```
但当目标地址偏移量超出该范围时，就无法通过一条分支指令完成跳转。此时需要先将目标地址（PC+偏移量）加载到寄存器，再使用绝对跳转指令`jirl`完成跳转：
``` text
li 	$r7, (PC+offset)	#	加载目标地址到寄存器r7
jirl 	$r0, $r7, 0 	#	跳转到目标地址(r7+0)
```
根据常量（PC+offset）的大小不同，宏指令`li`最终会被编译器扩展为1~4条汇编指令。
