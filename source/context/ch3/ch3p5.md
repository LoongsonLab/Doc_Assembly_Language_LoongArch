#	特权等级和特权指令概述

现代软件系统出于接口安全考虑，通常采用分层、分模块的设计和管理方式。不同层级和模块被赋予对处理器或其他硬件设备资源的不同访问权限，即不同的特权等级（Privilege Level，PLV）。简单的分层和分模块软件系统设计如图3-2所示。

通常来说，越靠近底层的模块，特权等级越高，能够获取的资源等级或权限也越高。龙芯架构中，处理器核分为4个特权等级，分别为PLV0~PLV3。其中，PLV0具有最高权限，也是唯一可以使用特权指令并访问所有特权资源的特权等级。PLV1~PLV3这3个特权等级在MMU采用映射地址翻译模式时具有不同访问权限。对于Linux系统，仅PLV0级对应核心态，通常建议以PLV3级对应用户态。

特权指令是具有特殊权限的指令，用于操作系统或其他系统软件完成特殊功能，例如改变系统工作方式、检测用户访问权限、修改虚拟存储器管理的段表和页表、完成任务创建和切换等，一般不直接提供给普通用户使用。龙芯基础指令集支持的特权指令包括CSR（Control and Status Register，控制状态寄存器）访问指令，用于软件访问CSR，包括读/写/修改CSR；IOCSR访问指令；Cache维护指令，用于Cache初始化和Cache一致性维护；TLB（Translation Lookaside Buffer，转译后备缓冲器）维护指令，用于TLB表维护；软件页表遍历指令，用于软件页表遍历过程中的目录项和页表项访问；其他特权杂项指令，包括从例外处理返回、进入调试模式和停止取指进入等待（IDLE）状态等。

例如，要获取当前进程运行在哪个处理器核上，可以通过CSR访问指令读取处理器编号（CPUID）控制状态寄存器，指令如下：
``` asm
csrrd 	$r7, 0x20
```
这里，CSR访问指令`csrrd`用于读取某个CSR寄存器信息，0x20为处理器编号CPUID控制寄存器的地址。处理器编号用于软件在多核系统中区分各个处理器核。通常处理器核号从0开始递增编号，例如龙芯3A5000处理器为4核，因此CPUID分别为0、1、2、3。

通常情况下，特权指令仅在PLV0特权等级下才能访问，因此应用软件开发者平时使用它的机会较少。当需要了解各种特权指令的详细说明和控制寄存器信息时，读者可查阅龙芯架构参考手册。
