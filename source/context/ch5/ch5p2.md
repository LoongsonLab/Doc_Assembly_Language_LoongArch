#	LoongArch寄存器使用约定

任何体系架构都会对其提供的寄存器作功能使用约定，用于说明函数调用时通过哪些寄存器传递参数、通过哪些寄存器保存返回值、哪些寄存器可以任意使用而无需保存旧值等。寄存器使用约定是汇编语言层面将程序拆分为函数的基础，使大型程序按模块编写成为可能。

LoongArch ABI对通用寄存器和浮点寄存器的使用都做了约定。

##	通用寄存器使用约定

LoongArch中定义的通用寄存器（General-Purpose Register，GPR）共32个，记为r0~r31。LoongArch中各个通用寄存器对应的别名和使用约定如表5-3所示。

|名称|别名|用途|在调用中是否保留|保存者|
|-|-|-|-|-|
|$r0      |$zero  |常数0                 |（常数）|不存在|
|$r1      |$ra    |返回地址               |否      |被调用者|
|$r2      |$tp    |线程指针               |不可分配 |不可用|
|$r3      |$sp    |栈指针                 |是      | 被调用者|
|$r4-$r5  |$a0-$a1|传参数寄存器、返回值寄存器 | 否     |不存在|
|$r6-$r11 |$a2-$a7|传参数寄存器            | 否     |不存在| 
|$r12-$r20|$t0-$t8|临时寄存器              | 否     |调用者| 
|$r21     |       |保留                   |不可分配 | 不可用|
|$r22     |$fp/$s9|栈帧指针、静态寄存器      |是 | 被调用者|
|$r23-$r31|$s0-$s8|静态寄存器              |是 | 被调用者|

表5-3按照使用功能的不同，将32个通用寄存器划分为几类，并给出了简要使用约定。

1.	寄存器别名

为了便于记忆和阅读，ABI为每个寄存器定义了具有功能含义的别名。别名通常由寄存器功能的英文首字母、数字或字母缩写组成。例如，寄存器r4的别名为a0，其中a代表arguments，即该寄存器可用作函数调用传参的第一个寄存器；寄存器r5的别名为a1，可用作函数调用传参的第二个寄存器；寄存器r3的别名为sp，sp是stack pointer的缩写，代表栈指针。编写汇编指令时，可以使用寄存器编号，也可以使用寄存器别名。下面两条指令的功能完全相同。
``` asm
addi.d 	$r3, $r3, 32
addi.d 	$sp, $sp, 32
```
这两条指令的功能都是实现寄存器与立即数32的加法运算。不过，使用别名sp可以让程序员清楚知道这是对栈指针的操作。在实际汇编语言编写过程中，更推荐使用寄存器别名，这样更便于理解指令语义。本书后续示例也将尽可能使用寄存器别名书写。

使用LoongArch寄存器别名时，需要包含头文件`regdef.h`，该文件已经定义了寄存器编号及其对应别名。

2.	寄存器功能介绍

表5-3汇总介绍了LoongArch中32个通用寄存器的功能。接下来按功能分别介绍这些寄存器的使用场景。

(1) zero寄存器

r0（别名zero）是常量寄存器。无论对其写入什么值，读取它的值时永远返回0。例如，要取一个变量的相反数，可以用zero寄存器和这个变量所在寄存器做减法，从而减少对立即数0的加载操作。
``` asm
sub.w 	$t5, zero, $t4 	//	这里t5和t4互为相反数
```
zero寄存器对一些合成指令也很重要，它提供了一种更简洁、清晰的编码方式。例如，LoongArch中常用的宏指令`move`，其对应的有效汇编指令可用`or`或`add.d`实现。
``` asm
//	宏指令 		---> 	//	有效汇编指令
move 	$t0, $t1 		or 	$t0, $t1, zero
```
这里简单解释一下宏指令。宏指令是为了方便软件编程或增强语义直观性而定义的一组指令，这些指令在编译时会由汇编器转换为处理器能够识别并执行的真实指令。也就是说，宏指令并不是架构直接提供的指令，而是由汇编器提供并识别的指令。汇编器负责将宏指令翻译成真实机器指令。

LoongArch中没有用于两个寄存器之间数据复制的真实`move`指令。上面的汇编指令`or t0,t1,zero`表示将寄存器t1和寄存器zero进行或运算，并将结果存入t0，这就实现了从寄存器t1到寄存器t0的数据复制。同样的功能，汇编器也可以使用LoongArch支持的真实汇编指令`add.d t0, t1, zero`来实现。

(2)函数调用与寄存器 v0～v1、a0～a7、ra

LoongArch ABI规定，发生函数调用时，寄存器a0~a7用于传递前8个整型参数或指针参数，其中a0和a1（别名也为v0和v1）也用于返回值，寄存器ra用于保存返回地址。

例如，对于有2个整型参数、1个整型返回值的加法函数调用，其对应的C语言代码如下：
``` c
int ret = add(2,3);
```
使用汇编语言来实现，代码如下：
``` asm
add:
add.w 	$a0, $a0, $a1
jirl 	$zero, $ra, 0
main:
li.w 	$a0, 0x2
li.w 	$a1, 0x3
bl 		add
```
其中，`add:`和`main:`称为标签，表示一个函数的开始。`main`函数的第1行和第2行分别将两个整型参数2、3存入寄存器a0、a1，作为函数`add`的参数。第3行的`bl`指令将当前PC+4存入寄存器ra，并跳转到函数`add`。`add`函数中的`add.w a0, a0, a1`完成两个参数的加法操作，并将结果写入a0（v0），作为函数`add`的返回值；`jirl zero, ra, 0`实现返回到函数`main`。

需要注意的是，LoongArch中v0、v1和a0、a1分别是同一组寄存器，即返回值和参数共用寄存器。因此，编写汇编代码时需要避免出现值覆盖问题。

关于传递的整型参数超过8个、参数中包含浮点数类型、返回值为结构体类型等复杂情况的调用规范，将在5.3节详细介绍。

(3)临时寄存器t0～t8和保存寄存器s0～s8

临时寄存器t0~t8中的字母t可理解为temporary，在函数中起临时变量作用。也就是说，在函数中使用这些临时寄存器时，不需要考虑保存旧值。

保存寄存器s0~s8中的s代表saved。当前函数应负责保证这些寄存器的值在函数返回时与函数入口处一致。如果函数内需要使用s0~s8中的某一个或几个寄存器，则在使用前需要将其旧值存储在栈上，并在函数返回前恢复旧值，从而保证在调用者看来这些寄存器的值没有变化。例如，某个函数中需要使用s0寄存器时，函数开始和结束时通常会有s0的进栈和出栈操作。
``` asm
st.d 	$s0, $sp, 32
...
ld.d 	$s0, $sp, 32
```

这里假设使用s0寄存器之前，将s0存放到栈位置sp+32处；省略号处可以任意使用s0；函数退出时，使用`ld.d`指令从之前的栈位置sp+32处恢复s0旧值。

(4)tp寄存器

tp寄存器用于支持线程局部存储（Thread-Local Storage，TLS）。TLS是一种线程局部变量的存储方法，可保证变量在线程内全局可访问，但不能被其他线程访问。例如，libc库中的`_Thread_local errno`变量就是典型的线程局部变量，用于标识当前线程最新的错误编号。LoongArch ABI专门占用一个寄存器指向当前线程的TLS区域，目的是实现该区域内变量的快速定位和访问，提高程序执行效率。通常，寄存器tp由系统libc库维护（负责读写），用户程序最好不要修改该寄存器。

(5)函数栈和寄存器sp、fp

在数据结构中，栈（Stack）是只允许在同一端进行插入和删除操作的动态存储空间。它按照先进后出的原则存储数据，即先进入的数据被压在栈底，最后进入的数据位于栈顶。函数栈也是一段动态存储空间，用于保存函数内的局部变量和相关寄存器，但使用上并没有数据结构中的栈那样严格。每个函数的参数数量和局部变量数量不同，函数栈空间大小也不尽相同。LoongArch ABI规定使用寄存器sp、fp记录每个函数栈的起始位置。具体函数栈使用约定将在5.4节详细介绍。

##	浮点寄存器使用约定

LoongArch可用的浮点寄存器也是32个，记为f0~f31。这32个浮点寄存器的使用约定如表5-4所示。

|名称|别名|用途|在调用中是否保留|保存者|
|-|-|-|-|-|
|$f0-$f1  |$fa0-$fa1 |传参数寄存器、返回值寄存器 | 否     |不存在| 
|$f2-$f7  |$fa2-$fa7 |传参数寄存器            | 否     |不存在| 
|$f8-$f23 |$ft0-$ft15|临时寄存器              | 否     |调用者| 
|$f24-$f31|$fs0-$fs7 |静态寄存器              | 是     |被调用者| 

相较于整数寄存器，浮点寄存器的使用约定较为简单。根据使用功能不同，浮点寄存器的别名也不同。寄存器f0~f7共8个浮点寄存器用于函数浮点数据的参数传递，别名分别为fa0~fa7。其中f0和f1还用于函数返回值，别名也可为fv0和fv1。临时寄存器别名包含字母t，共16个，即ft0~ft15；保存寄存器别名包含字母s，共8个，即fs0~fs7。

例如，要实现两个浮点数加法函数，其对应的C语言代码如下：
``` c
float fadd(float var1, float var2){
	return var1 + var2;
}
```
使用汇编语言来实现，代码如下：
``` asm
fadd:
fadd.s 		$fv0, $fa1, $fa0
jirl 		$zero, $ra, 0
```
其中，参数寄存器fa0、fa1分别存放变量var1、var2，浮点加法运算后的结果写入fv0，并通过`jirl`指令返回。
