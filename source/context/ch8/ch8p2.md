#	约束字符

约束字符是放在输入操作数和输出操作数前面的修饰符，用于说明操作数的类型、读写权限等。下面介绍常用的约束字符。

-	“=”：用于修饰输出操作数，表示该操作数可写，其先前的值将被丢弃，并由输出数据替换。

-	“+”：用于修饰输出操作数，表示该操作数可读可写。

-	“r”：表示该操作数是整型变量（用于修饰C语言中的 short、int、long 等），请求为其分配一个通用寄存器。

-	“f”：请求分配一个浮点寄存器，用于修饰C语言中的浮点变量（float 或 double 类型）。例如，要实现浮点数加法 `float ret = (float)a + (float)b;`，相应的内嵌汇编为：
``` c
float ret = 0;
asm("fadd.s %0,%1, %2\n\t"
:"=f"(ret)
:"f"(a),"f"(b)
);
```

-	“I”：表示该操作数是有符号的12位常量。当常数操作数小于12位时，可以使用此约束符。例如，实现带常数的加法操作：
``` c
asm("addi.w %0,%1\n\t"
	:"=r"(ret)
	:"r"(a),"I"(10)
);
```

-	“l”：表示该操作数是有符号的16位常量。当常数操作数大于12位但小于16位时，可以考虑使用此约束符。

-	“K”：表示该操作数是无符号的12位常量。当操作数为负数时，只能使用“I”或“l”；使用此约束符会报错。

-	“J”：表示该操作数是整数零。

-	“G”：表示该操作数是浮点数零。

-	“&”：表示该输出操作数是早期破坏操作数，即其值可能在所有输入操作数使用完之前被修改。

-	“m”：表示内存操作数，用于访存指令的地址加载和存储，常用于修饰C语言中的指针类型。例如，要将变量 a 的地址加载到指定寄存器 t0，内嵌汇编程序如下：
``` c
int* p = &a;
asm("ld $t0, %0 \n\t"
	:                     /*no output*/
	:"m"(p)
	:"$t0"
);
```
