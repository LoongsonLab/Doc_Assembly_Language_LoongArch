#	计算机体系架构的三类并行技术

计算机体系架构中提升性能的并行技术主要有3类，分别为指令级并行、数据级并行和任务级并行。

指令级并行是指在一个时钟周期内尽可能执行多条机器指令。典型的指令级并行技术包括指令流水线、多发射和乱序执行。指令流水线技术是指同一周期内可以有多条指令处于不同执行阶段，即通过时间重叠实现指令级并行，从而提高处理器吞吐率。目前许多处理器架构都采用多级流水线，龙芯处理器可以达到12级流水线。多发射技术通过增加处理器中的功能部件实现空间重复，例如增加4个加法器即可同时处理4条加法指令，从而实现一个周期执行多条指令。目前龙芯处理器采用四发射结构，即一个周期最多可以执行4条指令。乱序执行技术是指当遇到执行时间较长或执行条件暂不具备的指令时，将条件已经具备的后续指令提前执行，目的是提高指令流水线效率，充分利用指令之间潜在的可重叠性和不相关性。

数据级并行是指一条指令可以处理多个数据，通常称为单指令多数据流（Single Instruction Multiple Data，SIMD），例如一条指令完成4组或8组加法运算。其典型实现技术是向量指令。目前大多数体系架构都有自己的向量指令。LoongArch 基础指令集中包含采用向量指令的向量扩展（LSX）和高级向量扩展（LASX），其操作的向量位宽分别为128位和256位。

任务级并行包括线程级并行和进程级并行。任务级并行依赖处理器的多核结构。在单个处理器核心算力固定的情况下，多核并行计算是提升系统计算吞吐量的重要方式。目前市面上的处理器多为多核处理器。龙芯5000系列处理器用于桌面计算机时通常为4核，用于服务器时可为8核或16核。在多核处理器环境下，软件开发人员需要重点理解同步机制，即多个处理器核心之间如何正确并尽可能高效地协调共享数据。
