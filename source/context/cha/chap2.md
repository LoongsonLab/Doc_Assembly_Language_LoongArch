#	使用向量指令

对于计算密集型应用程序，使用向量指令通常可以获得较好的加速效果。以图像处理领域为例，图像常用的数据格式是 YUV（Y 表示亮度，即灰阶值；U、V 表示色度，用于描述色调和饱和度），通常 YUV 数据元素占用8位。在对这类数据进行大量加法运算时，如果使用通用基础指令集，首先需要使用一条 load 指令访问内存并取得第一个8位操作数，再使用一条 load 指令取得第二个8位操作数，随后使用一条 add 指令求和，最后使用一条 store 指令将结果写回内存。具体指令如下：
``` asm
ld.b   t1, addr1
ld.b   t2, addr2
add.w  t3, t1, t2
st.b   t3, addr3
```
虽然通用寄存器是32位或64位的，但处理这些数据时只使用其低8位，执行4条指令只能完成1组加法操作。

如果换用向量指令，例如使用龙芯高级向量扩展，向量位宽为256位，那么同样是4条指令，却可以处理32组数据，计算效率显著提高。指令示例如下：
``` asm
xvld     x1, addr1
xvld     x2, addr2
xvadd.b  x3, x1, x2
xvst     x3, addr3
```
使用向量指令的缺点是，向量寄存器复用浮点寄存器，可能出现浮点模式切换场景，从而产生性能开销。因此，在使用向量指令时，应避免向量指令和浮点指令同时出现在同一个函数中，同时应确保向量指令用于热点函数或循环计算体。所谓热点函数或循环计算体，是指在整个程序运行过程中被多次执行，或执行时间占比较大的函数或循环体。

由于篇幅有限，本书不再逐一列举 LoongArch 向量指令集。当需要对程序进行向量优化时，可以查阅龙芯架构参考手册中的向量指令集部分。
