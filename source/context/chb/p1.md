#	立即数加载

立即数（Immediate）是指直接嵌入在指令中的常数值。

在 LoongArch64 架构中，受 RISC（精简指令集计算机）设计原则影响，大多数指令只能直接处理16位或20位范围内的立即数。然而在实际编程中，程序员常常需要将32位甚至64位立即数加载到寄存器中。

LoongArch64 提供了 lu12i.w（加载高20位立即数）、ori（或运算）、lu32i.d（加载高32位）、lu52i.d（加载高52位）等指令，用于逐步构建大立即数。但手动编写这些指令序列既繁琐又容易出错。立即数加载相关伪汇编指令正是为解决这一问题而设计的：由汇编器完成繁琐的指令拆分工作，使程序员能够专注于代码逻辑本身。

##	li 伪指令

###	指令详解

li（Load Immediate）是 LoongArch64 中最基础的立即数加载伪指令，专门用于将常数值加载到通用寄存器中，其格式如下。
``` asm
li.w  rd, immediate    # 加载32位立即数
li.d  rd, immediate    # 加载64位立即数
```
指令参数说明如下：

-	li.w：w 表示 word（32位），加载32位宽立即数。
-	li.d：d 表示 double word（64位），加载64位宽立即数。
-	rd：目的通用寄存器（32个通用寄存器之一，编号 r0 至 r31）。
-	immediate：待加载的常量值（十进制或十六进制）。

汇编器会根据立即数的大小，自动选择最经济的实现方式：

-	若立即数可用单条指令加载，则展开为单条指令。比如 imm 在16位有符号范围内（-32768 到 32767），可转换为 addi rd, $zero, imm。如果 imm 在16位无符号范围内（0 到 65535），可转换为 ori rd, $zero, imm。
-	若立即数超出单条指令范围，则自动拆分为多条指令序列（如 lu12i.w + ori，或配合 lu32i.d 构建64位值）。
-	对于小立即数，li.w 和 li.d 的展开结果相同（如 li.w $t0, 4 等价于 ori $t0, $zero, 4）。
