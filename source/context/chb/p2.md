# 	算术指令

## 	move 伪指令

格式：
```asm
move rd, rs
```
说明：
- 将寄存器 `rs` 的值复制到寄存器 `rd`
- 汇编器转换为：`or rd, rs, $zero`

##	ud 伪指令

格式：
``` asm
ud rd,rj
```

说明：
-	该指令实现原子操作，将`rj`地址处的数值写入`rd`，`r1`寄存器的值写回`rj`地址。
-	指令等于amswap.w rd, $r1, rj

##	nop 伪指令

格式：
``` asm
nop 
```

说明：
-	该指令为空指令
-	指令等于andi $r0, $r0, 0
