#	算术指令

##	move 伪指令

格式如下：
``` asm
move rd, rs
```
说明如下：

-	把寄存器 `rs` 中的值复制到寄存器 `rd`。
-	汇编器通常将其展开为 `or rd, rs, $zero`。

##	ud 伪指令

格式如下：
``` asm
ud rd,rj
```

说明如下：

-	该指令用于原子交换操作：把 `rj` 指向地址中的值写入 `rd`，同时把 `r1` 寄存器的值写回 `rj` 指向的地址。
-	该伪指令等价于 `amswap.w rd, $r1, rj`。

##	nop 伪指令

格式如下：
``` asm
nop 
```

说明如下：

-	该指令不产生实际计算效果，用作空操作。
-	汇编器通常将其展开为 `andi $r0, $r0, 0`。
