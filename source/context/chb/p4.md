# 	位置无关代码

##	la伪指令

###	指令详解

la（Load Address）系列伪指令用于将符号的地址加载到通用寄存器，用于加载数据地址、函数地址等。其格式与变体形式如下：
``` asm
la          rd, symbol    # 等价于 la.global（默认行为）
la.global   rd, symbol    # 加载全局符号地址（可能经过GOT，默认模式）[reference:16]
la.local    rd, symbol    # 加载局部符号地址（PC相对寻址）[reference:17]
la.got      rd, symbol    # 经GOT（全局偏移表）加载符号地址[reference:18]
la.pcrel    rd, symbol    # PC相对寻址加载地址[reference:19]
la.abs      rd, symbol    # 绝对地址加载[reference:20]
```

汇编器会根据地址大小自动选择最优指令序列。
