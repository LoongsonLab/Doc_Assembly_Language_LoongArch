#	函数返回与跳转

##	call 伪指令

功能：调用函数，并自动保存返回地址。

语法：
``` asm
call target
call target, offset
```

参数：

-	`target`：目标地址（标签、函数名、寄存器）。
-	`offset`：可选偏移量（用于 PC 相对寻址）。

汇编器行为：

-	将下一条指令的地址（返回地址）保存到 `$ra`。
-	跳转到目标地址。
-	根据目标地址类型自动选择合适的指令序列。

底层实现：
``` asm
# 对于 PC 相对寻址（最常见）
pcaddu12i $t0, %pcrel_hi(target)  # 计算目标地址高20位
addi.d    $t0, $t0, %pcrel_lo(target)  # 添加低12位偏移
jalr.hb   $ra, $t0, 0            # 跳转并保存返回地址

# 对于寄存器间接寻址
jalr.hb   $ra, $target_reg, 0    # 跳转到寄存器中的地址
```

##  ret 伪指令

功能：从函数返回，跳转到 `$ra` 中保存的返回地址。

语法：
``` asm
ret
```

汇编器行为：

-	生成跳转到 `$ra` 的指令。
-	通常使用 `jr.hb $ra` 指令（Jump Register with Hazard Barrier）。

底层实现：
``` asm
jr.hb $ra  # 跳转到 $ra 中的地址，并插入指令屏障
```


##	jr 伪指令

功能：跳转到寄存器中指定的地址，是 `ret` 的底层形式。

语法：
``` asm
jr rs
jr rs, offset
```

参数：

-	`rs`：包含目标地址的寄存器。
-	`offset`：可选偏移量（在 LoongArch 中通常为0）。

与 `ret` 的区别：

-	`ret` 固定使用 `$ra` 作为跳转目标。
-	`jr` 可以使用任意寄存器。
-	`ret` 隐含函数返回语义，而 `jr` 是通用跳转。

##	条件分支伪指令

LoongArch 支持的条件分支伪指令如下。

| 伪指令 | 条件 | 说明 |
|--------|------|------|
| `bltz` | rs < 0 (有符号)  | Branch Less Than Zero |
| `bgtz` | rs > 0 (有符号) | Branch Greater Than Zero |
| `bgez` | rs >= 0 (有符号) | Branch Greater or Equal Zero |
| `blez` | rs <= 0 (有符号) | Branch Less or Equal Zero |
