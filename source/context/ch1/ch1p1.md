# 	计算机语言

前文所列举的语言统称为计算机语言。计算机语言是人与计算机之间进行交流的语言。计算机由一组电子器件构成，要使其完成特定工作，就需要向其输入能够识别并执行的语言（也称为指令）。与人类语言类似，计算机语言也具有一套标准语法规范，计算机正是依据这些规范理解用户意图并执行相应操作。

计算机语言种类繁多，从使用层次看，通常可分为机器语言、汇编语言和高级语言三类。简单来说，距离处理器最远、抽象层次最高的是高级语言，它通常需要经过更多编译或转换步骤后才能被计算机识别和执行，表达方式也更接近自然语言和数学公式，例如C、C++、Java等。汇编语言处于中间层次。距离计算机最近、抽象层次最低的是机器语言，它是唯一能够被计算机直接识别和执行的语言。绝大多数软件开发人员（或称程序员）通常使用更接近人类语言语法规则、也更易编写的高级语言开发程序，再通过编译器和汇编器将其逐步转换为机器语言，最终交由处理器执行并得到结果。这个流程如图1-1所示。

下面按照与计算机处理器的距离，以由近及远的顺序分别介绍机器语言、汇编语言和高级语言。

## 机器语言

机器语言是计算机能够直接识别和执行的程序语言，其表示形式为二进制。进制是一种计数方法。我们最熟悉的十进制使用0~9共10个数字，遵循“逢十进一”的规则；二进制只使用“0”和“1”两个数字，遵循“逢二进一”的规则。计算机硬件本质上由电路元件构成，最容易用有电和无电两种状态与外界交互，这两种状态也称为高电平和低电平，分别对应二进制数的“1”和“0”。每个二进制数字称为一位（bit）。

机器语言由多条机器指令（简称指令）组成。一条指令由固定长度的二进制数构成，用于指示计算机执行一个动作，例如加法运算、减法运算、与运算或从内存读取数据等。因此，指令是计算机执行操作的基本单位。计算机呈现给程序员的全部指令的集合称为指令集或指令系统。可以说，指令系统是软件与硬件之间的接口层，程序员正是通过这一接口指导处理器工作。常见指令系统包括x86、ARM等。中央处理器（Central Processing Unit，CPU）是计算机的核心部件，其主要功能是解释指令并处理软件中的数据。特定CPU只能识别特定指令，例如x86指令只能被采用x86指令集的处理器识别，不能被采用ARM或MIPS指令集的处理器识别。一般而言，指令集和体系架构在本书语境中含义相近，均涉及一组指令以及相关寄存器等资源。

龙芯指令系统中一条指令占用32位。例如，要让龙芯处理器完成一次加法操作，其机器指令可能如下：
``` c
0000 0010 1100 0001 0000 0000 0110 0011
```
这是一串难以直接理解的数字，因为人们很难直观读出这32个0和1组合所表达的语义。但机器指令并非无规律可循。与自然语言和高级计算机语言类似，机器指令也有语法规范。一条机器指令长度固定（例如龙芯指令长度为32位），由操作码和操作数两部分组成，操作数又可分为源操作数和目的操作数。下面以C语言为例进行类比。
``` c
long c = a + 2;
```
这里可以将符号“+”理解为操作码，表示该语句执行加法操作。变量a和常数2是源操作数，变量c是目的操作数，用于存放加法运算结果。机器指令的语法规范与此类似，不过机器指令中的操作码不仅要表示运算类别（如加法、减法、乘法等），还要表示参与运算的数据类型（如int、double、long等）。同时，机器指令中的操作数通常为寄存器（计算机中用于临时存储数据的器件）或常数。例如，龙芯指令集中加法运算指令的语法规范如图1-2所示。

从图1-2可以看出，在龙芯指令集中，一条指令的长度为32位。对于加法指令，32位中的高10位表示操作码。0b0000001010表示32位加法指令（ADDI.W），0b0000001011表示64位加法指令（ADDI.D）。接下来的12位表示一个常数；随后两个5位字段分别表示源寄存器操作数ri和目的寄存器操作数rd，ri和rd可以是龙芯指令集提供的32个通用寄存器中的任意一个。

对照图1-2，可以解读出这条机器指令的语义。其中高10位（0000 0010 11）为操作码，表示带立即数的64位整数（对应C语言的long类型）加法运算；接下来的12位（00 0001 0000 00）为第一个源操作数，该源操作数是常数，换算为十进制数值为64；再接下来的5位（00 011）为第二个源操作数，该源操作数是寄存器，换算为十进制数值为3，即第3个寄存器；最后5位（0 0011）为目的操作数，也是第3个寄存器。因此，这条机器指令的功能是将第3个寄存器的值与常数64相加，并将结果存入第3个寄存器。对应的龙芯汇编指令写法为`addi.d r3, r3, 64`。此条机器指令按语法规范可表示为
``` c
0000 0010 11 | 00 0001 0000 00 | 00 011 	| 0 0011
操作码		第一个源操作数	 第二个源操作数    目的操作数
```
要解读程序中每一条机器指令的含义，通常需要不断对照指令手册进行翻译。进一步来说，要让计算机完成一个实际功能，可能需要成千上万条这样的指令。如果直接使用机器指令编写程序，难度可想而知。因此，后来出现了更易阅读和编写的汇编语言以及高级语言。

## 汇编语言

汇编语言可以看作机器语言的符号化表示，它使用较易理解和记忆的字母、单词来代替特定机器指令。通过这种方式，程序更易阅读，其执行功能也更容易理解。例如，1.1.1小节中在龙芯指令架构下实现两个数加法操作，其对应的机器指令和汇编指令分别如下：
``` text
机器指令： 0000 0010 1100 0001 0000 0000 0110 0011
汇编指令： addi.d r3,r3,64
```
从汇编指令的书写形式中，可以更容易地解读这条指令的语义：实现寄存器r3和常数64的加法操作，并将结果写回寄存器r3。这样就省去了对照指令手册逐个翻译操作码和操作数的过程。一条汇编指令通常由助记符和操作数两部分组成。助记符对应机器指令中的操作码，例如这里的`addi.d`就是助记符，表示64位加法操作；操作数表示指令的计算对象，例如这里的两个r3寄存器和常数64。

通过这个例子可以看到，使用汇编语言时，程序员不必关心指令对应的具体二进制编码，汇编器会将其翻译为二进制机器语言，从而显著提高编程效率。

汇编语言和机器语言一样，都是与计算机体系架构强相关的低级语言。也就是说，使用龙芯汇编指令集编写的程序，在未经转换的情况下，不能运行在基于x86或ARM指令集的处理器上，反之亦然。

## 高级语言

高级语言是一个相对概念，通常可理解为越便于程序员高效编写的语言，其抽象层次越高。例如，C语言刚出现时，人们认为它比汇编语言更高级，因此称其为高级语言，而将汇编语言称为低级语言；当Java、Python等语言出现后，人们又认为C语言的抽象层次相对较低。本书所说的高级语言是相对于汇编语言而言的，指不再强依赖处理器硬件体系架构、表达方式更接近自然语言和数学公式的程序设计语言，例如C、C++、Java、Go等。这些语言本身独立于处理器架构，具有各自的语法规则，但不能被计算机直接识别和执行，需要经过编译器和汇编器的翻译，转换为机器指令后才能由处理器识别并执行。例如，要实现一个数的累加运算，使用C语言可写为：
``` c
++a;
```
一条语句即可完成变量a的累加功能。如果a的初始值为1，那么`++a`执行后，a的值为2。这条语句对应的汇编语言指令通常至少需要3条：首先从内存地址加载a的初始值到寄存器，然后执行该寄存器与常数1的加法操作，最后将结果写回内存地址。这个过程可用如下龙芯汇编指令表示：
``` asm
load	r3,[addr]	//	从内存地址addr加载值到寄存器r3
add 	r4,r3,1 	//	加法计算r3+1，将结果写到寄存器r4
store 	r4,[addr]	//	把寄存器r4的值写回到内存地址addr
```
对比后不难发现，C语言比汇编语言更直观，也更便于程序员编程。而且，实现同样功能的高级语言程序通常只需编写一次，面向不同体系架构平台的机器语言可由对应编译器生成。

高级语言设计思想发展的核心目标，是使程序员能够更快速、高效地编程。编程思想经历了面向过程（将一个功能块定义为一个函数或方法，以C语言为代表）、面向对象（将相关数据、函数或方法组织为一个整体进行管理，以Java语言为代表）、函数式编程（强调高阶函数等特性，Java、Groovy、Scala、JavaScript等语言均提供相关支持）等阶段。未来还可能出现更偏向应用意图表达的设计思想，即只需描述程序要完成的任务，程序便可自动生成算法并完成处理。高级语言设计思想的持续演进，使计算机语言越来越接近人类语言，也更加智能，编程效率不断提高，程序员因而能够将更多精力投入复杂业务场景的解决。
