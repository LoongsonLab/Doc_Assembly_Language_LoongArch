#	基础浮点指令类

【例1】 单/双精度浮点数的加法运算
``` asm
fadd.s 		$f0, $f2, $f1 	#	单精度浮点数加法，f0[31:0] = f2[31:0] + f1[31:0]
fadd.d 		$f0, $f2, $f1 	#	双精度浮点数加法，f0[63:0] = f2[63:0] + f1[63:0]
```
这两条指令分别实现两个单精度浮点数和两个双精度浮点数的加法运算，并将结果写入浮点寄存器 f0。

【例2】 双精度浮点数乘加运算
``` asm
fmadd.d 	$f0, $f1, $f2, $f3 	#	双精度浮点数乘加，f0 = f1*f2 + f3
```
这里的浮点数乘加指令是 LoongArch 中较少见的四操作数指令，包括一个目的寄存器和3个源寄存器。它实现类似 `a = b * c + d` 的先乘后加运算，运算和舍入方式遵循 IEEE 754-2008 标准规范。

【例3】 写出如下程序的汇编指令
``` c
float a = 1.0;
float b = 2.0;
float c = a + b;
```
这段 C 语言语句涉及浮点数加载、加法运算和浮点数存储3类功能指令，具体对应的 LoongArch 汇编指令如下：
``` asm
fld.s 	$f0, $r12, 0 	#	从内存加载1.0到浮点寄存器f0
fld.s 	$f1, $r12, 4 	#	从内存加载2.0到浮点寄存器f1
fadd.s 	$f2, $f0, $f1 	#	将1.0 + 2.0结果写入浮点寄存器f2
fst.s 	$f2, $r12, 8 	#	将结果写回内存
```
这里假设寄存器 r12 存放变量 a 所在内存的起始地址，变量 b、变量 c 紧挨着变量 a 存放。因此，加载变量 b 时的地址为 r12 + 4，写回变量 c 的地址为 r12 + 8。这里变量 b 和 c 的内存偏移值都在12位以内，因此使用 fld.s 和 fst.s。如果内存偏移位置超过12位宽，访存指令就需要使用相应的 fldx/fstx。

【例4】 编写如下C语言语句对应的汇编指令
``` c
float a = 1.0;
float b = 2.0;
float c = (a < b)? 1 : 0 ;
```
这段语句用于对两个浮点变量 a 和 b 进行比较。比较条件成立时变量 c 赋值为1，否则赋值为0。使用 LoongArch 汇编指令实现上述逻辑如下：
``` asm
li.w 		$r4, 0 			#	加载0到寄存器r4
fcmp.slt.s 	fcc0,$f0,$f1 	#	如果f0 < f1成立，则条件标志寄存器fcc0置1，否则置0
bceqz 		fcc0, 4 		#	如果fcc0等于0，跳转到nop，否则继续执行下一条li指令
li.w 		$r4, 1
nop
```
这里假设变量 a 存放在浮点寄存器 f0，变量 b 存放在浮点寄存器 f1，变量 c 存放在寄存器 r4。因为当前 a 为1.0、b 为2.0，所以指令 `fcmp.slt.s fcc0, f0, f1` 执行后 fcc0 的值为1，bceqz 不会发生跳转，而是继续执行指令 `li.w r4, 1`，将变量 c 修改为1。

【例5】 编写如下C语言语句对应的汇编指令
``` c
float fv = (a < b)? a : b;
```
这段 C 语言语句中，浮点变量 fv 的最终结果为变量 a 和 b 中的最小值。对应的汇编语句可以如下：
``` asm
fcmp.slt.s 		fcc0, $f0, $f1
bceqz 			fcc0, 0x4
fmov.s 			$f2, $f0
fmov.s 			$f2, $f1
```
这里假设变量 a 存放在浮点寄存器 f0，变量 b 存放在浮点寄存器 f1，变量 fv 存放在浮点寄存器 f2 中。指令 `fcmp.slt.s fcc0, f0, f1` 完成 `a < b` 的比较，并将结果存入 fcc0。指令 `bceqz fcc0, 0x4` 判断 fcc0 中的结果：如果为0（`a < b` 条件不成立），则跳转4字节到指令 `fmov.s f2, f1` 位置，完成将 b 赋值给 fv；否则不跳转，继续执行下一条指令 `fmov.s f2, f0`，完成将 a 赋值给 fv。

【例6】 编写如下C语言语句对应的汇编指令
``` c
float fv = 3.0;
double dv = fv;
```
上面语句的目的是实现单精度浮点数 fv 向双精度浮点数 dv 的转换。对应的汇编指令如下：
``` asm
fcvt.d.s 	$f1, $f0
```
这里假设单精度浮点数变量 fv 存放在浮点寄存器 f0 中，双精度浮点数变量 dv 存放在浮点寄存器 f1 中。那么指令 `fcvt.d.s f1, f0` 就实现了 fv 向 dv 的转换。

【例7】 当浮点寄存器 f1 的值分别为 1.2340f 和 1.5340f 时，在如下指令执行后，寄存器 f0 的值为多少？
``` asm
frint.s 	$f0, $f1
```
指令 frint.s 用于将单精度浮点数转换为整数数值对应的单精度浮点数，即按照浮点数舍入方式进行转换。当浮点寄存器 f1 的值为 1.2340f 时，指令执行后浮点寄存器 f0 的值为 1.0000f；当浮点寄存器 f1 的值为 1.5340f 时，指令执行后浮点寄存器 f0 的值为 2.0000f。

【例8】 实现浮点数 double 类型到 long 类型的强制转换
``` c
long ret = (long)3.145;	//	ret结果为3
```
对应的 LoongArch 汇编指令可以为：
``` asm
ftintrz.l.d 	$f30, $f1 	//	f1存放浮点数3.145，指令结束后f30为3.000
movfr2gr.d 		$r7, $f30 	//	将f30中的3.000移动到整型寄存器r7，指令结束后r7为3
```

【例9】 定点数转浮点数示例
``` c
float fval = 3;
```
此语句对应的 LoongArch 汇编指令为：
``` asm
li.w 		$r12, 0x3
movgr2fr.w	$f0, $r12
ffint.s.w 	$f0, $f0
```
这里 li.w 完成将定点数3加载到通用寄存器 r12；movgr2fr 负责将 r12 中的数据搬运到浮点寄存器 f0；最后 ffint.s.w 负责将 f0 中的定点数3转换为浮点数3.0，并重新存入 f0。

【例10】 使能浮点控制状态寄存器 fcsr0 的 Enable 域中的所有位（VZOUI）
``` asm
li 			$r7, 0x1f
movgr2fcsr 	$r0, $r7 	//	这里使用通用寄存器r0来标识fcsr0
```
