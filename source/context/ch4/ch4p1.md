#	浮点数存储方式和数值范围

计算机中的数据均以二进制方式存储，但由于浮点数具有特殊性，无法采用整数的补码存储方式。因此，IEEE规定了两种基本浮点数格式：单精度和双精度。单精度浮点数（对应C语言数据类型`float`）宽度为32位，双精度浮点数（对应C语言数据类型`double`）宽度为64位。它们的组织格式如图4-1所示。

```{image} ../../img/ch4/pic_4_1.png
:alt: 单精度和双精度的组织格式
:class: bg-primary
:scale: 80 %
:align: center
```

单精度浮点数由1位符号s（0表示正数，1表示负数）、8位偏置指数e、23位小数f这3部分组成；双精度浮点数由1位符号s、11位偏置指数e、52位小数f这3部分组成。根据偏置指数e取值不同，浮点数的计算方式和可表示的数值范围也不同，具体可分为以下3类。

##	规格化的值

这是最普遍的情况。当偏置指数e区域既不全为0，也不全为1（单精度浮点数中全1为0xFF，双精度浮点数中全1为0x7FF）时，如图4-2所示，计算得到的浮点数值定义为规格化的值。此时浮点数的计算公式为

单精度浮点数：(-1)<sup>s</sup>x2<sup>e-127</sup>x1.f

双精度浮点数：(-1)<sup>s</sup>x2<sup>e-1023</sup>x1.f

```{image} ../../img/ch4/pic_4_2.png
:alt: e区域既不为0也不为1
:class: bg-primary
:scale: 80 %
:align: center
```

比如某一个浮点寄存器低32位中存放的二进制值为
``` c
0100 0000 1011 1000 0000 0000 0000 0000
||_________|___________________________|
s 	e(8位)                    f(23位)
```
按照上述单精度浮点数计算公式，可以得出其对应的十进制浮点数约为5.75。其中，s为0，e为129（二进制10000001），f为3670016（二进制011 10000000 0000 0000 0000）。

##	非规格化的值

当偏置指数e区域全为0时，如图4-3所示，其表示的数称为非规格化的值，可用于表示数值0和非常接近0的数。具体来说，当f全为0时，如果s位为0则表示+0.0，如果s位为1则表示-0.0；当f不全为0时，单精度浮点数计算公式为

(-1)<sup>s</sup>x2<sup>-126</sup>x0.f

此时，得到的是一个非常接近0的数值。

```{image} ../../img/ch4/pic_4_3.png
:alt: e区域为0
:class: bg-primary
:scale: 80 %
:align: center
```

##	正负无穷大或NaN

当偏置指数e区域全为1时，可以表示的浮点数是无穷大或非数字（Not a Number，NaN），如图4-4所示。具体来说，当f全为0时，如果s位为0则表示正无穷大+INF，如果s位为1则表示负无穷大-INF；当f不全为0时，结果值被称为NaN。当某些运算的结果不能表示为实数或无穷大时，就会返回NaN值。
