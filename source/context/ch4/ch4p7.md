#	浮点转换指令

浮点转换指令用于实现单精度浮点数与双精度浮点数之间、浮点数与定点数之间的转换。LoongArch支持的浮点转换指令如表4-8所示。

```{image} ../../img/ch4/t2p_4_8_2.png
:scale: 80 %
:align: center
```

在表4-8中，指令名前缀为`fcvt`的指令用于实现单精度浮点数和双精度浮点数之间的转换。其中，后缀`.s.d`表示双精度浮点数（double）向单精度浮点数（float）转换，后缀`.d.s`表示单精度浮点数向双精度浮点数转换。指令名前缀为`ffint`的指令用于实现定点数到浮点数的转换（其中第二个`f`可理解为from），其后缀类型包括`.s.w`、`.s.l`、`.d.w`、`.d.l`，分别表示32位整数转单精度浮点数、64位整数转单精度浮点数、32位整数转双精度浮点数、64位整数转双精度浮点数。指令名前缀为`ftint`的指令用于实现浮点数向定点数的转换（其中字母`t`可理解为to），其后缀类型包括`.w.s`、`.l.s`、`.w.d`、`.l.d`，分别表示单精度浮点数转32位整数、单精度浮点数转64位整数、双精度浮点数转32位整数、双精度浮点数转64位整数。指令名前缀为`frint`的指令用于实现浮点数向整数数值的浮点数转换（其中`r`可理解为round to），其后缀类型包括`.s`、`.d`，分别表示单精度浮点数转换和双精度浮点数转换。
