#	浮点访存指令

浮点访存指令与第03章介绍的普通整数访存指令功能类似，用于实现对内存中数据的读操作（访问）或写操作（存储）。这里的数据通常为浮点类型。浮点访存指令没有原子访存指令，只分为浮点普通访存指令和浮点边界检查访存指令。

##	浮点普通访存指令

浮点普通访存指令用于从指定内存地址读取（访问）一个单精度浮点数或双精度浮点数到寄存器，也用于将一个单精度浮点数或双精度浮点数写入（存储到）指定内存地址。LoongArch支持的浮点普通访存指令如表4-3所示。

在表4-3中，浮点访存指令`fld.s`、`fldx.s`、`fst.s`、`fstx.s`用于在内存与浮点寄存器fd低32位之间传送一个32位数据，浮点寄存器fd的高32位为任意值；浮点访存指令`fld.d`、`fldx.d`、`fst.d`、`fstx.d`用于在内存与浮点寄存器fd之间传送一个64位数据。浮点访存指令的内存地址计算方式分为基于常数的base+offset方式（即表中rj+si12）和基于寄存器的base+index方式（即表中rj+rk）。其中，si12表示一个有符号12位立即数。

##	浮点边界检查访存指令

浮点边界检查访存指令与浮点普通访存指令一样，用于从指定内存地址读取数据到寄存器，或将数据写入指定内存地址。二者区别在于，浮点边界检查访存指令在读写内存前会进行条件检查，确认该地址是否位于给定地址范围内；如果条件不满足，则终止读写操作并触发边界检查例外。LoongArch支持的浮点边界检查访存指令如表4-4所示。

:::{tip}
浮点边界检查访存指令仅在LA64架构下支持。
:::

```{image} ../../img/ch4/t2p_4_4.png
:alt: LoongArch支持的浮点边界检查访存指令
:class: bg-primary
:scale: 80 %
:align: center
```

表4-4中，指令名前缀中的`gt`表示仅当通用寄存器rj的值大于rk时，才会从寄存器rj存放的内存地址取回一个单精度（指令名后缀为`.s`）或双精度（指令名后缀为`.d`）浮点数，并写入浮点寄存器fd；否则终止访存操作并触发边界检查例外。`le`与`gt`的条件相反，即仅当寄存器rj小于或等于rk时才执行访存指令，否则触发边界检查例外。对于应用程序，触发边界检查例外时会收到段错误信号（SIGSEGV）。

第03章已经介绍过，整数边界检查访存指令可用于整数数组的安全索引，以及时发现数组下标越界访问。同理，浮点边界检查访存指令可用于浮点数组的安全访问。这里不再举例说明。
