#	汇编源文件中的汇编指令

汇编源文件中的汇编指令包括体系架构汇编手册提供的汇编指令，以及编译器提供的汇编宏指令。下面分别介绍。

##	汇编指令

汇编源文件中的汇编指令与架构汇编手册提供的指令通常是一一对应的关系，只是在书写格式上略有差异。以加法指令为例，汇编手册中的写法为 `add.w r4, r5, r6`，而在汇编源文件中的写法为 `add.w $r4, $r5, $r6`，即汇编源文件要求在寄存器名前添加符号 `$`。同时，汇编源文件也支持使用寄存器别名，例如 `add.w $a0, $a1, $a2`。

##	汇编宏指令

完善的体系架构生态通常会提供丰富的宏指令，以尽量向开发者屏蔽目标文件中不直观的汇编指令用法，或隐藏符号重定位等细节，从而方便开发者快速编写汇编程序。在程序的汇编阶段，汇编器会根据汇编时已知的信息，将宏指令展开为一条或多条机器指令。下面列举一些LoongArch ABI支持的汇编宏指令。

1.	空指令

空指令表示该指令没有实际功能语义，但可用于地址对齐填充。LoongArch编译器支持的空指令为：
``` asm
nop
```
该宏指令最终会被汇编器翻译为如下汇编指令。
``` asm
andi 	$r0, $r0, 0x0
```

2.	立即数加载宏指令

立即数加载宏指令用于将32位或64位立即数加载到一个通用寄存器中，加载过程不需要借助其他寄存器中转。LoongArch编译器支持的立即数加载宏指令有如下两种：
``` asm
li.w 	rd, imm31
li.d 	rd, imm64
```
根据待加载立即数的长度不同，宏指令 li.w 需要1～2条LoongArch汇编指令实现，li.d 需要3～4条LoongArch汇编指令实现。例如，将立即数0加载到寄存器 a0 的宏指令 `li.w $a0, 0`，会被汇编器最终实现为如下LoongArch指令。
``` asm
addi.w 	$r4, $r0, 0
```
第03章已经详细介绍过不同长度立即数加载的汇编指令写法，这里不再赘述。

3.	地址加载宏指令

地址加载宏指令用于将符号地址加载到一个通用寄存器中，且加载过程不需要借助其他寄存器中转。LoongArch编译器支持的地址加载宏指令有如下两种：
``` asm
la.local 	rd, label
la.global 	rd, label
```
其中，la.local 用于加载同一汇编源文件内的符号地址，la.global 用于加载其他汇编源文件中的符号地址。指令中的 label 为目标文件中的标签，通常代表一个符号的起始地址。例如，在汇编源文件中使用宏指令 `la.local $r4, .LC0`，在可重定位目标文件中会被汇编器用如下真实汇编指令实现。
``` asm
pcaddu12i 	$r4, 0
addi.d 		$r4, $r4, 0
```

4. 	跳转宏指令

跳转宏指令用于有条件或无条件的符号地址跳转，且实现过程不需要借助其他寄存器中转。LoongArch编译器支持的几种典型跳转宏指令如下：
``` asm
jr 		rd
bl 		symbol
bgt 	rj, rd, label
ble 	rj, rd, label
bgtz 	rj, rd, label
blez 	rj, rd, label
```
其中，宏指令 jr 用于无条件跳转到目标地址，该地址存放在寄存器 rd 中。通常情况下使用寄存器 r1，具体写作 `jr r1`，用于函数调用返回。该宏指令最终实现为如下LoongArch指令：
``` asm
jirl 	$r0, $r1, 0
```
宏指令 `bl symbol` 用于函数调用。对于同一文件内的函数调用，例如调用同文件内的函数 test，写作 `bl test` 即可。对于外部文件中的函数调用，例如调用基础 libc 库的函数 printf，可使用指令 `bl %plt(printf)`。使用宏指令 `bl symbol` 时，开发者无需过多关注函数地址重定位的细节问题，可以显著提高编写汇编程序的效率。

宏指令 bgt、ble 等用于有条件跳转。例如，bgt 表示当 rj 大于 rd 时，跳转到标签 label 处。以下列指令为例：
``` asm
label_1:
	addi.d 	$r5, $r5, 2
	bgt 	$r4, $r5, label_1
	nop
```
这里指令 `bgt $r4, $r5, label_1` 用于判断寄存器 r4 是否大于 r5。条件成立时，程序跳转到标签 label_1 处重新执行 `addi.d $r5, $r5, 2`；否则执行指令 nop。

LoongArch ABI中还定义了更多宏指令，例如 `move rd, rs` 用于将寄存器 rs 的数据复制到寄存器 rd，`la.got rd, label` 用于通过GOT（Global Offset Table，全局偏移表）将一个地址加载到寄存器 rd。后续还可能加入更多宏指令，读者需要时可以查阅龙芯架构参考手册的ABI部分。
